About Me

I build and research multi-agent AI systems where independent language models cooperate, reason, and make decisions together. My work focuses on solving the hardest failure modes in agentic systems: how groups form sustainable rules, how shared memory avoids contamination, and how models handle strategic risk.

In ELICIT, I designed a multi-agent simulation framework that tests how LLM agents negotiate climate treaties and self-govern under risk. Agents choose whether to contribute to shared pools, vote to rewrite constitutional rules, and manage an empirical Loss and Damage Fund. In SEAM, I study agentic memory architecture to stop memory collapse and information poisoning. By comparing update policies across network topologies, I showed how structured curation protects agent stability over hundreds of rounds.

Beyond research, I build applied ML systems that deploy to production. My background in Economics and Mathematics at IBA Karachi gives me a strong quantitative foundation for building real-time forecasting pipelines, hybrid retrieval engines, and scalable MLOps architectures.

SEAM: Shared Evolving Agent Memory

Tags: Multi-Agent Systems, LLM Agents, Agentic Memory, AI Safety, Network Topologies, Ollama

This project studies what happens when self-evolving agents share memory with each other. It measures how quickly bad experiences or false lessons spread through a population across different network topologies. The benchmark compares naive overwrite, raw history logs, and structured incremental updates on deterministic resource tasks. Results show that structured curation with ring communication prevents performance collapse while isolating errors.
